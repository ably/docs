Version 0.9.0 of the Chat SDK for Swift has been released. This release includes many changes to the public API, which aim to achieve the following:

1. Matching the functionality and API of the JavaScript version of this SDK.

2. Improving method naming to meet the [Swift API Design Guidelines](https://www.swift.org/documentation/api-design-guidelines/).

For the full changelog, please visit the [GitHub releases page](https://github.com/ably/ably-chat-swift/releases/tag/0.9.0).
