Version 2.4.0 of the JS Client Library has been released.

It adds the ability to pass a `wsConnectivityCheckUrl` client option to Ably instances. Additionally, a Push plugin is now available to be loaded via a CDN link.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.4.0).
