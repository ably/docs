Version 0.3.1 of the Spaces SDK has been released.

It includes a fix for not being able to import CJS Spaces module bundle due to `ERR_REQUIRE_ESM` error and improvements to docstring comments across all Spaces SDK classes.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/spaces/releases/tag/0.3.1).
