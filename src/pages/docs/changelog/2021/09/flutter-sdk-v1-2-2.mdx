Ably Flutter v1.2.2 is now available for preview, adding support for push notifications, including device activation with Ably (including device registration with APNs / FCM) and subscribing devices for push notifications. Check out the [dedicated documentation](https://github.com/ably/ably-flutter/blob/main/PushNotifications.md) and the [example app](https://github.com/ably/ably-flutter/tree/main/example/lib/push_notifications) for more information.
