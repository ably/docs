Version 1.2.50 of the JS Client Library has been released. It introduces improvements to the logging API, implements handling of the 204 status code in `PaginatedResource`, adds deprecation warnings for some options along with improvements to deprecation messages, and fixes typing for the `Crypto.getDefaultParams()` method. For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/1.2.50).
