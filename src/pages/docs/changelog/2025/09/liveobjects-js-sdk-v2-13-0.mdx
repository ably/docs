Version 2.13.0 of the JS Client Library has been released.

This release introduces version 4 of the Ably protocol and includes changes to the structure of the experimental annotations and message fields. It also adds `connectionId` of the client who submitted the LiveObject operation to the `LiveObjectUpdate` in subscription callbacks.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.13.0).
