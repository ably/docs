Version 2.0.1 of the JS Client Library has been released.

It includes a fix for not being able to import from "ably" in React Native when using ably v2, and a fix for `TextEncoder`/`TextDecoder` APIs are not defined in React Native for ably v2.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.0.1).
