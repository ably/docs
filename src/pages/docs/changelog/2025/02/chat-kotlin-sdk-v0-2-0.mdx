We are pleased to announce the release of message updates and deletes in the Kotlin SDK for Ably Chat.

Users can now update or delete their messages in real-time, ensuring greater flexibility and control over conversations. Updated messages are instantly synchronised across all clients, maintaining consistency and clarity in chats.

**Full changelog**: [Visit the Github release page](https://github.com/ably/ably-chat-kotlin/releases/tag/v0.2.0).

**Documentation:** [Explore the Ably Chat Docs](https://ably.com/docs/products/chat).
