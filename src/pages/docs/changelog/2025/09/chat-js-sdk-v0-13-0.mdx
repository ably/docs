Version 0.13.0 of the Chat SDK for TypeScript and React has been released.

This version improves the `usePresence` React Hook, providing more a cleaner API with more obvious semantics. It also simplifies the React API by removing unnecessary references to core SDK types, in favour of using the provided callbacks and hook features.

For the full changelog, please visit the [GitHub releases page](https://github.com/ably/ably-chat-js/releases/tag/0.13.0).
