A LiveObjects operation specified a path within an object tree that did not resolve to any object. The path may be incorrect, or the objects it points to may not exist.

## What you should do

Check the path in the operation. It didn't resolve to any object, so correct the path, or make sure the objects it points to exist before the operation runs.

## Why it happens

The path specified in the operation did not resolve to any object in the tree. The path may be wrong, or the objects it refers to may not exist.

## What you'll see

The error is reported with code 92005 and HTTP status 400. The message is `no objects matched path: <path>`.
