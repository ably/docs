Today we are excited to announce a new product, [LiveSync](https://ably.com/docs/products/livesync), in early access.

LiveSync enables you to stream changes in your database to frontend clients at scale. LiveSync is database agnostic but currently only supports PostgreSQL in this version. It uses Ably's global message delivery network to sync user data in realtime.

LiveSync is made up of two components: the [Database Connector](https://ably.com/docs/livesync/connector) and the [Models SDK](https://ably.com/docs/livesync/models).

- The Database Connector is a backend service that watches changes on an outbox table in your database, that you can transactionally write to along with updates to other tables, and publishes those changes over Ably Channels. Currently, the connector component will need to be hosted on your systems, although we provide guidance for doing that in documentation.

- The Models SDK is a frontend library that simplifies subscribing to changes in data models, applying optimistic updates and merging them with confirmed updates.
