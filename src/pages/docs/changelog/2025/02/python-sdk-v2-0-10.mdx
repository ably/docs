Version 2.0.10 of the Python Library has been released.

This update adds support for `pee` 12 and fixes the inability to pass a JSON string value for a `capability` parameter when creating a token.

For the full changelog, please visit [GitHub release page](https://github.com/ably/ably-python/releases/tag/v2.0.9).
