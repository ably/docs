We are pleased to announce the release of server-side batching.

When enabled, Ably will group any published messages within a user-defined timeframe into a batch, before sending them to subscribers.

This feature makes messages more cost-efficient in high-throughput use cases, such as fan engagement platforms, where key moments can cause large surges in message counts through reactions and celebrations.

Server-side batching also allows you to have an increased number of clients present in a single channel when it is enabled.

Read the [server-side batching documentation](https://ably.com/docs/messages/batch#server-side) for further information and instructions on how to enable it.
