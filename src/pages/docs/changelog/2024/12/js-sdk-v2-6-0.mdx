Version 2.6.0 of the JS Client Library has been released.

This update improves the behavior of presence events, updates the experimental attributes on the `Message` type to support edits and deletes, and improves the package build process, allowing to reference specific branches of the `ably-js` repo in `package.json`.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.6.0).
