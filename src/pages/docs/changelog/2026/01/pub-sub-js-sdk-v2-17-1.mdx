Version 2.17.1 of the JS Client Library has been released.

It fixes an issue where a client could send a non-monotonic `msgSerial` after a stale connection reset, and fixes missing capabilities in the `CapabilityOp` type.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.17.1).
