If you are using the ['persist last message' feature](https://ably.com/docs/storage-history/storage#persist-last-message), that allows the channel to remember the last message to be published on it for up to a year, you can now retrieve this message using the History API (previously it was only retrievable using [rewind](https://ably.com/docs/channels/options/rewind)). See [our history API documentation](https://ably.com/docs/storage-history/history#channel-parameters) for how to do this.
