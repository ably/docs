Version 3 of the Ably Kafka Connector has been released. This is a major version upgrade and includes increased throughput via batch-publishing to Ably, as well as support for Amazon MSK.

For more information on the changes and how to upgrade, please see the [changelog](https://github.com/ably/kafka-connect-ably/releases/tag/v3.0.0) and the [upgrade guide](https://github.com/ably/kafka-connect-ably/blob/v3.0.0/UPDATING.md).
