A new API key could not be created because the application had reached the maximum number of keys permitted by its limits.

## What you should do

Delete API keys the application no longer needs, or [contact Ably support](https://ably.com/support) to raise the [key limit](https://ably.com/docs/platform/pricing/limits), then create the new key.

## Why it happens

The application already has the maximum number of API keys its package permits, so another could not be created. This limit applies per application.

## What you'll see

The error is reported with code 40127 and HTTP status 401. The message is `maximum number of keys per application exceeded`.
