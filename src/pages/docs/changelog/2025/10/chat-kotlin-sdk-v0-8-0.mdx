Version 0.8.0 of the Chat SDK for Kotlin (Android/JVM) has been released.

This version adds support for Chat protocol v4 to enhance message handling, introduces a more ergonomic subscription API with destructuring, and replaces Gson with a lightweight custom JSON implementation to reduce dependencies and improve portability.

For the full changelog, please visit the [GitHub releases page.](https://github.com/ably/ably-chat-kotlin/releases/tag/v0.8.0)
