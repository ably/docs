Version 1.3.0 of the Ably Go SDK has been released.

This release adds support for VCDiff delta-compressed messages. When enabled, the SDK transparently reconstructs full message payloads from server-provided deltas and base content, reducing bandwidth without requiring changes to your application code.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-go/releases/tag/v1.3.0).
