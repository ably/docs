## Conformed Package Name and Version

With this release we are conforming our version numbering to match that used in our other client libraries. This reflects the fact that this plugin is heading towards compliance with version 1.2 of our [Features Specification](https://ably.com/docs/client-lib-development-guide/features/), also aligning with the underlying implementations of [ably-cocoa](https://github.com/ably/ably-cocoa) and [ably-java](https://github.com/ably/ably-java).

**Package Name Change**

We're now simply `ably_flutter` (renamed from `ably_flutter_plugin`, as we realised the `_plugin` suffix was somewhat superfluous).
