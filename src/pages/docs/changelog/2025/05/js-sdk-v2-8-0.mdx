Version 2.8.0 of the JS Client Library has been released.

It adds the `.device()` method to `RestClient` and `RealtimeClient` which return the `LocalDevice` object for push notifications, and adds `LocalDevice.channelSubscriptions()` method which uses device auth to get push channel subscriptions only for the local device.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.8.0).
