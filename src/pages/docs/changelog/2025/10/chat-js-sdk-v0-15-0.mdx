Version 0.15.0 of the Chat SDK for Typescript and React has been release.

This version has a number of changes aimed at improving the overall API. Several types have been renamed for consistency and state accessors on the Typing and Occupancy interfaces are now properties to align with other SDK APIs.

Presence event filtering has been simplified, and improvements have also been made to the structure of reaction events, so they are clearer and key attributes are easily accessible.

Additionally, this release includes improvements for serial validation and promise handling, along with standardized error messages and more specific error codes for better developer experience.

For the full changelog and upgrading guide, please visit the [GitHub release page](https://github.com/ably/ably-chat-js/releases/tag/0.15.0).
