Version 2.2.0 of the JS Client Library has been released.

It introduces an improvement to the `ClientOptions.logHandler` function: the library will now pass the log level at which a log has been raised as a second argument to this function. It also includes a fix for pings stacking when calling `Connection.ping()` if none ever succeed.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.2.0).
