Version 0.2.0 of the Ably Chat SDK for JavaScript has been released.

This release introduces support for **React** and **React Native**, including custom contexts and hooks, to provide a deeper integration with this ecosystem. You can check out the full suite of React features in the [React readme](https://github.com/ably/ably-chat-js/blob/main/src/react/README.md).

Also included are a number of documentation improvements, changes to how the CDN bundle is formed and other bugfixes.

For a full list of changes, please head over to the [change log](https://github.com/ably/ably-chat-js/releases/tag/0.2.0).
