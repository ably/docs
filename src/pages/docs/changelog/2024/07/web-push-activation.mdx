Version 2.3.0 of the JS Client Library has been released.

With this release, ably-js clients can now be activated as a target for web push notifications. See our [official docs](https://ably.com/docs/push/configure/web) for instructions on how to start publishing web push notifications using Ably.

For the full changelog, please see the [full release notes on GitHub](https://github.com/ably/ably-js/releases/tag/2.3.0).
