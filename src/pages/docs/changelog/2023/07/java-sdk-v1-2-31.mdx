Version 1.2.31 of the Java/Android Client Library SDK has been released. This update includes a fix for the incremental backoff of reconnection attempts, as well as removing a number of legacy, undocumented error codes. For more details, please see the full [release notes](https://github.com/ably/ably-java/releases/tag/v1.2.31) on GitHub.
