Version 2.6.1 of the JS Client Library has been released.

This update removes some unused experimental attributes from the `Message` type, while adding support for upcoming message summaries. It also includes multiple improvements to type definitions and internal message handling.

For the full changelog, please visit [GitHub release page](https://github.com/ably/ably-js/releases).
