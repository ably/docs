Version 1.22.2 of the Go Client Library  has been released.

This version adds the `endpoint` client option, and deprecates the `environment`, `restHost` and `realtimeHost` client options.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-go/releases/tag/v1.2.22).
