Client library release

[https://github.com/ably/ably-ios/releases/tag/1.0.10](https://github.com/ably/ably-ios/releases/tag/1.0.10)

Important changes include:

- RTN23a idle timeout [#638](https://github.com/ably/ably-ios/issues/638).

- Move to DISCONNECTED on unexpected WebSocket close [#655](https://github.com/ably/ably-ios/issues/655).

- Deadlock: should dispatch in the user queue when removing an observer of an EventEmitter [#640](https://github.com/ably/ably-ios/issues/640).

- Presence map should use the `memberKey` as key rather than the `clientId` [#641](https://github.com/ably/ably-ios/issues/641).

- Presence map shouldn't be accessible [#631](https://github.com/ably/ably-ios/issues/631).

- Carthage support [#639](https://github.com/ably/ably-ios/pull/639).

This release is compatible with **Xcode 7.3**, **Xcode 8** and  **Xcode 9**.
