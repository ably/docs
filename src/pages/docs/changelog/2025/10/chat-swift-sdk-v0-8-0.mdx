Version 0.8.0 of the Chat SDK for Swift has been released.

This version improves on the Message interface, to provide a cleaner, more nested arrangement. It's also a transition to a new, more advanced protocol version (v4).

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-chat-swift/releases/tag/0.8.0)
