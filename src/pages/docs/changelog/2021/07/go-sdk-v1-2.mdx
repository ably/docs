For this release, we focused mainly on improving the Realtime component of the SDK. The previous release only supported the currently depreciated version 0.8 of the [Ably Client Library Specification](https://ably.com/documentation/client-lib-development-guide/features), but this version supports the latest version of the specification.

Since the functionality of the realtime library has significantly expanded during the transition from version 0.8 to 1.2, the changes have affected almost all components of the library including:

- RealTime Client

- Connection management and error handling

- Channel management

The [REST API](https://ably.com/documentation/rest-api/beta) has also been aligned with version 1.2 of the Ably Client Library specification, including Authentication and Encryption capabilities.

Full [release notes](https://github.com/ably/ably-go) and [changelog](https://github.com/ably/ably-go/blob/main/CHANGELOG.md) on GitHub.
