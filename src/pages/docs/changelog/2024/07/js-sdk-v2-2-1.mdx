Version 2.2.1 of the JS Client Library has been released.

It includes a fix for an occasion whereby a channel would attempt to automatically reattach from an inappropriate state, and improves the type information so that `ErrorInfo` interface now extends the `Error` interface.

For the full changelog, please visit the [GitHub release page](https://github.com/ably/ably-js/releases/tag/2.2.1).
