As part of our [Protocol Adapters](https://ably.com/adapters) service layer, MQTT is now available as a third party protocol compatible to work with Ably.

You can easily setup clients to use the MQTT protocol with Ably by following the steps from [our documentation](https://ably.com/docs/mqtt).

[Read why everyone is talking about MQTT, in a blog post by Srushtika, our Dev Advocate.](https://ably.com/blog/why-is-everyone-talking-about-mqtt-e5ffd23aa25b)

Alternatively, you can follow this [step-by-step tutorial](//this%20step-by-step%20tutorial%20to%20build%20an%20old-school%20game%20of%20snake%20using%20the%20MQTT%20protocol%20with%20Ably.) to build an old-school game of snake using the MQTT protocol with Ably.
