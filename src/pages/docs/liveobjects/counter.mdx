`LiveCounter` is a synchronized numerical counter that supports increment and decrement operations. It ensures that all updates are correctly applied and synchronized across clients in realtime, preventing inconsistencies when multiple clients modify the counter value simultaneously.

<If lang="javascript,swift,java">

You interact with `LiveCounter` through a [PathObject](/docs/liveobjects/concepts/path-object) or by obtaining a specific [Instance](/docs/liveobjects/concepts/instance).

<If lang="swift">
<Aside data-type='note'>
Mutation methods like `increment` and `decrement` are asynchronous: they suspend with `try await` until the operation completes. Reads are synchronous and run locally, so they need no `await`. Subscription callbacks fire on the configured callback queue, which is the main queue by default, so you can update your UI directly from them.
</Aside>
</If>
<If lang="java">
<Aside data-type='note'>
Mutation methods like `increment` and `decrement` return a `CompletableFuture<Void>`. Current examples use `.join()` for brevity, which blocks the calling thread. In production code, compose the future with `thenCompose`/`thenAccept`/`exceptionally` rather than blocking on it. See the [quickstart](/docs/liveobjects/quickstart/java#step-4) for details.
</Aside>
</If>

## Create a counter <a id="create"/>

Create a `LiveCounter` using the `LiveCounter.create()` static method and assign it to a path:

<Code>
```javascript
import { LiveCounter } from 'ably/liveobjects';

// Create a counter with initial value 0
await rootObject.set('visits', LiveCounter.create(0));

// Create a counter with initial value 100
await rootObject.set('score', LiveCounter.create(100));

// Create a counter without specifying initial value (defaults to 0)
await rootObject.set('clicks', LiveCounter.create());
```

```swift
// rootObject obtained from channel.object.get()

// Create a counter with initial value 0
let visits = LiveCounter.create(initialCount: 0)

// Assign the counter to the 'visits' key on the channel object
try await rootObject.set(key: "visits", value: .liveCounter(visits))

// Create a counter with initial value 100
let score = LiveCounter.create(initialCount: 100)

// Assign the counter to the 'score' key on the channel object
try await rootObject.set(key: "score", value: .liveCounter(score))

// Create a counter without specifying initial value (defaults to 0)
let clicks = LiveCounter.create()

// Assign the counter to the 'clicks' key on the channel object
try await rootObject.set(key: "clicks", value: .liveCounter(clicks))
```

```java
// rootObject obtained from channel.object.get()

// Create a counter with initial value 0
LiveCounter visits = LiveCounter.create(0);

// Assign the counter to the 'visits' key on the channel object
rootObject.set("visits", LiveMapValue.of(visits)).join();

// Create a counter with initial value 100
LiveCounter score = LiveCounter.create(100);

// Assign the counter to the 'score' key on the channel object
rootObject.set("score", LiveMapValue.of(score)).join();

// Create a counter without specifying initial value (defaults to 0)
LiveCounter clicks = LiveCounter.create();

// Assign the counter to the 'clicks' key on the channel object
rootObject.set("clicks", LiveMapValue.of(clicks)).join();
```
</Code>

`LiveCounter.create()` returns a value type that describes the initial value for a new counter. The actual object is created when assigned to a path. Each assignment creates a distinct object with its own unique ID:

<Code>
```javascript
const counterValue = LiveCounter.create(0);

// Each assignment creates a different object
await rootObject.set('counter1', counterValue);
await rootObject.set('counter2', counterValue);

// counter1 and counter2 are different objects with different IDs
const id1 = rootObject.get('counter1').instance()?.id;
const id2 = rootObject.get('counter2').instance()?.id;
console.log(id1 === id2); // false
```

```swift
let counterValue = LiveCounter.create(initialCount: 0)

// Each assignment creates a different object
try await rootObject.set(key: "counter1", value: .liveCounter(counterValue))
try await rootObject.set(key: "counter2", value: .liveCounter(counterValue))

// counter1 and counter2 are different objects with different IDs
let counter1Instance = try rootObject.get(key: "counter1").instance()
let counter2Instance = try rootObject.get(key: "counter2").instance()
if case .liveCounter(let c1)? = counter1Instance,
   case .liveCounter(let c2)? = counter2Instance {
    print(c1.id == c2.id) // false
}
```

```java
LiveCounter counterValue = LiveCounter.create(0);

// Each assignment creates a different object
rootObject.set("counter1", LiveMapValue.of(counterValue)).join();
rootObject.set("counter2", LiveMapValue.of(counterValue)).join();

// counter1 and counter2 are different objects with different IDs
Instance counter1Instance = rootObject.get("counter1").instance();
Instance counter2Instance = rootObject.get("counter2").instance();
if (counter1Instance != null && counter2Instance != null) {
    System.out.println(counter1Instance.asLiveCounter().getId()
        .equals(counter2Instance.asLiveCounter().getId())); // false
}
```
</Code>

## Get counter value <a id="value"/>

Access a `LiveCounter` through a [PathObject](/docs/liveobjects/concepts/path-object) for path-based operations, or obtain a specific [Instance](/docs/liveobjects/concepts/instance) to work with the underlying object directly. <If lang="javascript">Use the `value()` method to get the value of the `LiveCounter`:</If><If lang="swift">Cast with `asLiveCounter()` and use the `value()` method to get the value of the `LiveCounter`:</If><If lang="java">Cast with `asLiveCounter()` and use the `value()` method to get the value of the `LiveCounter`:</If>

<Code>
```javascript
const rootObject = await channel.object.get();

// PathObject access: path-based operations that resolve at runtime
const visits = rootObject.get('visits');
console.log(visits.value()); // e.g. 5

// Instance access: reference to a specific counter object
const visitsInstance = rootObject.get('visits').instance();
console.log(visitsInstance?.value()); // e.g. 5
```

```swift
let rootObject = try await channel.object.get()

// PathObject access - Double, or nil when the path doesn't resolve to a counter
print(try rootObject.get(key: "visits").asLiveCounter().value() as Any) // e.g. 5.0

// Instance access - value is a non-optional Double
if case .liveCounter(let counter)? = try rootObject.get(key: "visits").instance() {
    print(try counter.value) // e.g. 5.0
}
```

```java
LiveMapPathObject rootObject = channel.object.get().join();

// PathObject access - Double, or null when the path doesn't resolve to a counter
System.out.println(rootObject.get("visits").asLiveCounter().value()); // e.g. 5.0

// Instance access - value() returns a non-null Double
Instance visitsInstance = rootObject.get("visits").instance();
if (visitsInstance != null) {
    System.out.println(visitsInstance.asLiveCounter().value()); // e.g. 5.0
}
```
</Code>

<If lang="javascript">
<Aside data-type="note">
Calling `value()` on a `PathObject` may return `undefined` if a primitive value or `LiveCounter` instance cannot be found at that path. Calling `value()` on an `Instance` returns `undefined` if the instance is not a primitive or `LiveCounter`. Learn more about reading values on a [`PathObject`](/docs/liveobjects/concepts/path-object#read-values) and [`Instance`](/docs/liveobjects/concepts/instance#read-values).
</Aside>
</If>
<If lang="swift">
<Aside data-type="note">
Calling `value()` on a `PathObject` returns `nil` if the path is missing or doesn't hold a counter. Reading `value` on a `LiveCounterInstance` never returns `nil`, because it is a non-optional property and the `asLiveCounter()` cast has already refined the type. Learn more about reading values on a [`PathObject`](/docs/liveobjects/concepts/path-object?lang=swift#read-values) and [`Instance`](/docs/liveobjects/concepts/instance?lang=swift#read-values).
</Aside>
</If>
<If lang="java">
<Aside data-type="note">
Calling `value()` on a `PathObject` returns `null` if the path is missing or doesn't hold a counter. Calling `value()` on a `LiveCounterInstance` never returns `null`, because the `asLiveCounter()` cast has already checked the type. Learn more about reading values on a [`PathObject`](/docs/liveobjects/concepts/path-object?lang=java#read-values) and [`Instance`](/docs/liveobjects/concepts/instance?lang=java#read-values).
</Aside>

## Get compact object <a id="compact"/>

<If lang="javascript">
Get a numeric representation of the counter using the `compact()` or `compactJson()` methods. These methods return the same result as `value()`:

<Code>
```javascript
// Get a PathObject to a LiveCounter stored in 'visits'
const visits = rootObject.get('visits');
console.log(visits.compact());  // e.g. 5

// Get the Instance of a LiveCounter stored in 'visits'
const visitsInstance = rootObject.get('visits').instance();
console.log(visitsInstance?.compact());  // e.g. 5
```
</Code>

When calling these methods on a `LiveMap`, nested `LiveCounter` objects are included as a `number`:

<Code>
```javascript
// Get a PathObject to a LiveMap stored in 'stats'
const stats = rootObject.get('stats');
console.log(stats.compact());  // e.g. { visits: 5 }

// Get the Instance of a LiveMap stored in 'stats'
const statsInstance = rootObject.get('stats').instance();
console.log(statsInstance?.compact());  // e.g. { visits: 5 }
```
</Code>
</If>

<If lang="swift">

## Increment a counter <a id="increment"/>

Increment the value of a `LiveCounter` using the `increment()` method. You can specify an amount to increment by, or use the default increment of 1:

<Code>
```javascript
// PathObject: increment counter at path
await rootObject.get('visits').increment(5);  // increment by 5
await rootObject.get('visits').increment();   // increment by 1 (default)

// Instance: increment specific counter instance
const visitsInstance = rootObject.get('visits').instance();
await visitsInstance?.increment(5);   // increment by 5
await visitsInstance?.increment();    // increment by 1 (default)
```

```swift
// PathObject: increment counter at path
let visits = rootObject.get(key: "visits").asLiveCounter()
try await visits.increment(amount: 5)  // increment by 5
try await visits.increment()           // increment by 1 (default)

// Instance: increment specific counter instance
if case .liveCounter(let counter)? = try rootObject.get(key: "visits").instance() {
    try await counter.increment(amount: 5)  // increment by 5
    try await counter.increment()           // increment by 1 (default)
}
```

```java
// PathObject: increment counter at path
LiveCounterPathObject visits = rootObject.get("visits").asLiveCounter();
visits.increment(5).join();  // increment by 5
visits.increment().join();   // increment by 1 (default)

// Instance: increment specific counter instance
Instance visitsInstance = rootObject.get("visits").instance();
if (visitsInstance != null) {
    visitsInstance.asLiveCounter().increment(5).join();  // increment by 5
    visitsInstance.asLiveCounter().increment().join();   // increment by 1 (default)
}
```
</Code>

## Batch multiple operations <a id="batch"/>

Group multiple counter operations into a single atomic message using the `batch()` method. All operations within the batch are sent as one logical unit which succeed or fail together:

<Code>
```javascript
// PathObject: batch operations on counter at path
await rootObject.get('visits').batch((ctx) => {
  ctx.increment(5);
  ctx.increment(3);
  ctx.decrement(2);
});

// Instance: batch operations on specific counter instance
const visitsInstance = rootObject.get('visits').instance();
await visitsInstance?.batch((ctx) => {
  ctx.increment(10);
  ctx.decrement(5);
});
```
</Code>

## Subscribe to updates <a id="subscribe"/>

Subscribe to `LiveCounter` updates to receive realtime notifications when the value changes.

`PathObject` subscriptions observe a location and automatically track changes even if the `LiveCounter` instance at that path is replaced. `Instance` subscriptions track a specific `LiveCounter` instance, following it even if it moves in the channel object.

<Aside data-type="further-reading">
Learn more about [`PathObject`](/docs/liveobjects/concepts/path-object#subscribe) and [`Instance`](/docs/liveobjects/concepts/instance#subscribe) subscriptions.
</Aside>

<Code>
```javascript
// PathObject: observe location - tracks changes even if counter instance is replaced
const visits = rootObject.get('visits');
const { unsubscribe } = visits.subscribe(() => {
  console.log('Visits:', visits.value());
});

// Later, stop listening to changes
unsubscribe();

// Instance: track specific counter instance - follows it even if moved in object tree
const visitsInstance = rootObject.get('visits').instance();
if (visitsInstance) {
  const { unsubscribe } = visitsInstance.subscribe(() => {
    console.log('Visits:', visitsInstance.value());
  });

  // Later, stop listening to changes
  unsubscribe();
}
```

```swift
// PathObject: observe location - tracks changes even if counter instance is replaced
let visits = rootObject.get(key: "visits").asLiveCounter()
let subscription = try visits.subscribe { _ in
    print("Visits: \(String(describing: try? visits.value()))")
}

// Later, stop listening to changes
subscription.unsubscribe()

// Instance: track specific counter instance - follows it even if moved in object tree
if case .liveCounter(let counter)? = try rootObject.get(key: "visits").instance() {
    let instanceSub = try counter.subscribe { _ in
        print("This counter instance updated")
    }

    // Later, stop listening to changes
    instanceSub.unsubscribe()
}
```

```java
// PathObject: observe location - tracks changes even if counter instance is replaced
LiveCounterPathObject visits = rootObject.get("visits").asLiveCounter();
Subscription subscription = visits.subscribe(event ->
    System.out.println("Visits: " + visits.value()));

// Later, stop listening to changes
subscription.unsubscribe();

// Instance: track specific counter instance - follows it even if moved in object tree
Instance visitsInstance = rootObject.get("visits").instance();
if (visitsInstance != null) {
    Subscription instanceSub = visitsInstance.asLiveCounter().subscribe(event ->
        System.out.println("This counter instance updated"));

    // Later, stop listening to changes
    instanceSub.unsubscribe();
}
```
</Code>

<If lang="javascript">
Alternatively, use the `subscribeIterator()` method for an async iterator syntax:

<Code>
```javascript
// PathObject: observe location - tracks changes even if counter instance is replaced
const visits = rootObject.get('visits');
for await (const _ of visits.subscribeIterator()) {
  console.log('Visits:', visits.value());

  if (someCondition) {
    break; // Unsubscribes
  }
}

// Instance: track specific counter instance - follows it even if moved in object tree
const visitsInstance = rootObject.get('visits').instance();
if (visitsInstance) {
  for await (const _ of visitsInstance.subscribeIterator()) {
    console.log('Visits:', visitsInstance.value());

    if (someCondition) {
      break; // Unsubscribes
    }
  }
}
```
</Code>
</If>

<If lang="swift">
Alternatively, every `PathObject` and counter instance exposes an `events()` method returning an [`AsyncStream`](https://developer.apple.com/documentation/swift/asyncstream) that you can consume with `for await`. Breaking out of the loop, or cancelling the enclosing task, automatically unsubscribes. See the [quickstart](/docs/liveobjects/quickstart/swift#step-6) for an example.
</If>

<If lang="java">
The Java SDK has no `subscribeIterator()` equivalent; a listener plus the returned `Subscription` is the only subscription form.
</If>
